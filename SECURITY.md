# Security Policy

## Supported versions

Security fixes are provided for the latest stable release on the `main` branch. Upgrade to the latest patch release before reporting issues against older versions.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Email security reports to the maintainers listed in `composer.json`, or use GitHub's private vulnerability reporting if enabled for this repository.

Include:

- Description of the issue and impact
- Steps to reproduce
- Affected versions
- Suggested fix (if available)

We aim to acknowledge reports within a few business days.

## Security documentation

Operators and integrators should review [docs/security.md](docs/security.md) for deployment hardening, safe defaults, and configuration guidance.
